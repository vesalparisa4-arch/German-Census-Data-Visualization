# German-Census-Data-Visualization
German Census Data Visualization

University of Göttingen | M.Sc. Computational Biology and Bioinformatics

Project Overview

Exploratory analysis and visualization of German Census 2022 data, focusing on demographic patterns, population distributions, and regional differences.

Technologies

* Python
* Pandas and NumPy
* Matplotlib and Plotly
* Scikit-learn (PCA)
* Jupyter Notebook

Key Features

* Data cleaning, filtering, and transformation
* Analysis of large-scale demographic datasets
* Interactive visualizations and statistical charts
* Population distribution and demographic comparisons
* Principal Component Analysis (PCA)
* Interpretation and documentation of analytical results

Relevance to Business Intelligence

This project demonstrates practical skills in data preparation, data quality assessment, exploratory analysis, and communicating complex findings through effective visualizations.

These skills are directly transferable to reporting, dashboard development, and data-driven decision-making.
